refactor(ui): 换掉模板脸 —— 纸墨色系 + 手绘线性图标

改的是"一眼像生成出来的后台模板"这个观感问题，不是加功能。

配色（src/index.css @theme）
- 覆盖 Tailwind 自带 slate：冷灰蓝 → 带土黄的暖灰（纸/墨）。
  这样全站不用改一行类名就整体换肤；换品牌色只改这一块。
- brand：靛蓝 → 朱红（印章/批改笔），作为唯一强调色
- emerald/amber/red 降饱和：苔绿 / 赭石 / 深朱，去掉荧光感
- 新增 --font-display（衬线），只用于标题与关键数字

组件
- Card：去掉 shadow-sm，改 1px 墨线 + 小圆角；padded 档位分移动端/桌面
- Button：圆角收到 md；主按钮朱红实底加深边；次按钮改描边（不再一堆灰底按钮糊成一片）
- Badge / Progress：圆角收小，Progress 由胶囊改细条
- Segmented：外框描边 + 激活项描边，去掉"白胶囊+投影"
- WordCard：rounded-2xl → rounded-md，标题用衬线

图标与文案
- BottomTabBar：⌂ A ↻ ✓ ▤ ⚙ 等字符图标 → 手写 SVG 线性图标（24 栅格，currentColor）
  字符字形随系统字体变，粗细基线对不齐，是廉价感主因
- TopBar：🔍 / ☀ / ☾ → SVG；品牌名用衬线
- 去掉 🔥（连续天数）、🎉（本组完成）两处 emoji
- 仪表盘页头：连续天数降级为小字；三项数据改"细线分隔的记账本一行"

图表
- 掌握度四色、趋势两色改低饱和土系（不再用 #4f6ef7 / #10b981 那套默认色）
- 热力图：绿阶 → 纸白/赭黄/朱红暖阶
- 修 bug：HeatmapLegend 的色块用 fill-* 类名（对 HTML span 无效）→ 改 bg-*，图例此前是全透明的

其他
- 图标重新生成：品牌色 #2563eb → #ad4324（scripts/gen-icons.ts）
- index.html theme-color、manifest theme_color 同步

验证：typecheck 0 / lint 0 / 254 测试通过 / build 通过
