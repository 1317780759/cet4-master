### 本轮踩坑
- **首次提交混入翻译代码**：上一轮遗留了 11 个已暂存的翻译文件，`git add .gitignore .github docs .workbuddy` 不会清空暂存区，直接 commit 会把它们一起带走。用 `git reset --soft HEAD~1` + `git reset` 回退后，**按路径逐组 add 并用 `git diff --cached --name-only` 逐组复核**才干净。
  ⇒ **教训：分组提交前先 `git reset` 清空暂存区**，否则上一次 `git add` 的残留会污染下一次提交。
- **`git status --porcelain` 对已暂存文件仍计数** → 「90 个改动」里12 个是已暂存的重复计数，reset 后变78 属正常，不是文件丢失。用 `git ls-files --error-unmatch` 复核文件是否仍被跟踪。
- `.gs.txt` 是在修好 `.gitignore` **之前**创建的，规则修好后新文件不再被忽略，但**已有**的它仍会被 `add -A` 捞走 → 规则修复后应主动删一次存量临时文件。
- PowerShell 脚本里 `if/else` 表达式直接跟在管道后会让整个命令 exit 1且不落盘；改用 `$out = if (...) {...} else {...}` 再 `Set-Content`。
