### 环境摩擦备忘（本机 Windows，反复踩）
- Git Bash shim 损坏：`dirname` / `ls` / `grep` / `head` / **`rm`** 均不可用（`rm` 被 safe-bin 劫持且依赖坏掉的 `dirname`）
- PowerShell **不回显 stdout** → 一律 `| Out-File -Encoding utf8 <path>` 后再 `Read`（**默认 UTF-16 会被判为二进制**）
- PowerShell `Remove-Item` 在本机对这批文件无效 → 最终用 **Node `fs.unlinkSync`** 才删掉临时文件
- 临时文件一律写 **`$env:TEMP`**，**禁止**写工作区（曾因写 `public/data/` 与 `.workbuddy/` 两次污染）
- `pnpm` 的 stderr 在 PowerShell 里会被误报成 NativeCommandError → 关键校验用 `node node_modules/...` 直调绕开
