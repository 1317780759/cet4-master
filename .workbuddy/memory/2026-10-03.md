## 界面去"模板脸"改造（commit 5d622af，20 文件 / +377 -98）

用户反馈「界面有点太 AI 了」。定位到根因不是单点，而是三处默认选择叠加：
冷灰蓝 `slate` + 靛蓝主色 + 全套圆角阴影 = 一眼生成的后台模板。

### 关键手法：覆盖 Tailwind 自带色名（省掉全站改类名）
在 `src/index.css` 的 `@theme` 里直接重定义 `--color-slate-50..950`：
冷灰蓝 → 带土黄的暖灰（纸/墨）；`brand` 靛蓝 → 朱红 `#ad4324`；
emerald/amber/red 降饱和（苔绿/赭石/深朱）。
**全站不用改一行类名即整体换肤**，换品牌色只改这一块。
⚠️ 这是"改写框架默认语义"的取舍：务必在文件里写明原因（已写），否则后来者会困惑。

### 其余改动
- 图标：底栏 `⌂ A ↻ ✓ ▤ ⚙`、顶栏 `🔍 ☀ ☾` → 手写 SVG（24 栅格 / currentColor）。
  字符字形随系统字体变、粗细基线对不齐，是廉价感主因
- 删 emoji：🔥（连续天数）、🎉（本组完成）
- 组件：Card 去 shadow-sm 改 1px 墨线 + 小圆角；次按钮灰底 → 描边；
  Badge/Progress 圆角收小，Progress 胶囊 → 细条；WordCard `rounded-2xl` → `rounded-md`
- 排版：新增 `--font-display`（衬线）只用于标题与关键数字；统计数字加 `.tabular` 等宽
- 图表：掌握度/趋势改低饱和土系；热力图绿阶 → 纸白/赭黄/朱红暖阶

### 顺手修的真 bug
`HeatmapLegend` 色块用 `fill-*` 类名，但那是 HTML `<span>`——`fill` 只对 SVG 生效，
**图例色块此前全透明**。已拆成 `LEVEL_FILL`（rect 用）与 `LEVEL_BG`（span 用）两套。
